# Anderssons Rörservice

Färdig statisk webbplats med 18 HTML-sidor, CSS, JavaScript och lokala bilder.
Ingen installation eller byggprocess behövs.

## Lägg upp på GitHub

1. Packa upp ZIP-filen.
2. Lägg innehållet i mappen `anderssons-rorservice-github` direkt i ditt repos rot, så att `index.html` ligger överst.
3. Spara filerna i GitHub.
4. Om du använder GitHub Pages: välj publicering från din huvudgren och repots rotmapp.

Länkar och bilder är anpassade för både en egen domän och en GitHub Pages-adress med reponamn i sökvägen.

## Ändra webbplatsen

- `index.html` – startsidan.
- Övriga `.html`-filer – undersidor.
- `style.css` – utseende och mobilanpassning.
- `script.js` – menyer och tangentbordsnavigering.
- `assets/` – bilder, originallogotyp och typsnitt.

Logotypen behåller företagets originalform, med svarta konturer och vita ytor.
Google-omdömena är ett statiskt urval av enskilda femstjärniga recensioner från företagets befintliga webbplats. De uppdateras inte automatiskt och visas inte som ett samlat snittbetyg.
Interiörbilder används som inspiration, inte som utförda referensprojekt.
Typsnittets licens finns i `assets/FONT-LICENSE.txt`.

## Förhandsvisa lokalt

Öppna `index.html` i en webbläsare, eller använd en lokal webbserver.
